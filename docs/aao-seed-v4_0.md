The ontology recovery, which is the day's finding and changes a standard
Altify decomposed its own relationship-map dimensions and its insight card types into authored question sets years ago and ships them behind the Help me select wizard and the What is a Goal link. Recovered verbatim from production on 2 August: Support has five questions, Political three with three-way options and Not sure as a first-class answer, Coverage three, Buyer Role none at all. Each insight type carries a three-question admission test except Solution, which carries four, three of them about links to other cards.
This falsifies a glossary claim. Section B says that for a schema-sourced proposition the field label plus the value set is the rubric, and that there is no sentence to find because Altify never wrote one. Altify wrote eleven. Schema-sourced propositions now get verbatim authored text like the record-sourced side, which closes a real asymmetry. The text lives in the managed package UI and not in any queryable table; ALTF__Translation__c is empty and the platform Translation object holds only language enablement.
Two hazards from the same read. The stored answer paths disagree with the stored values on live rows, because a Select manually toggle leaves the old path behind, so the questions are the asset and the answers are exhaust. And a Solution card with no edges fails Altify's own published definition, which is why the missing-relation flag is the vendor's test rather than our invention.

Ruled 2 August, all in corrections v2.3
Ontology owns every rung, so Support is what Altify's tree computes from five propositions, and the one-per-source law and the minus-three-to-plus-three clamp are withdrawn for ontology-backed dimensions, surviving only as the inference fallback where no ontology exists. Coverage is a count of our own Sources and never reaches a model. Insight admission tests are guidance, not gates, and their text stays out of the reader's input. Guidance goes only where we hold evidence. Dedup is type-blind. Machine confirmation is an autonomy level. Solutions from line items are state and their edges are evidence. The missing-relation flag is keyed on deal plus relation kind, rolling up and naming the rows inside it. Cold seeding is per dimension: Support resets to Neutral because its questions are about this deal's solution, Political carries under a one-year bound, Buyer Role never seeds, Coverage needs no seed because it counts everything. Contention is unbounded but aggregated. Flags get no charter, because nothing may gate a flag being raised. Contention splits three ways and the configurable part is authored at setup and frozen. Persona is the People charter's fourth emission, additive only, never removed.
