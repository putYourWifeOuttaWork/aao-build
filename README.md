# aao-sandbox

Altify Always On — schema and deterministic plumbing, built in the `altify--aossb2`
sandbox. Metadata is the source; git is the artifact.

**Read in this order, first, every session:**

1. `BUILD_JOURNAL.md` — what has happened, what was verified, what is owed. Always first.
2. `docs/aao-field-tables-v0_8.md` — the closed field tables for six objects.
3. `docs/aao-flags-and-guidance-v1_0.md` — Flag, and guidance topology.
4. `docs/aao-corrections-v1_0.md` — the Answer/Claim correction. Where this disagrees
   with anything else, it wins.
5. `docs/aao-code-build-brief-v1_0.md` — the build brief this repo was created from.

Production is read-only, unconditionally. The only target org is `altify--aossb2`.
